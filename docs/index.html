Semantic

Meaning-carrying colours. These are deliberately not the same tokens as the brand accent: when accent and success are one token, neither reading is reliable.

R2 — the maize rule. Maize reaches only 1.44:1 on the light ground, so in light theme it is a ground, never a mark: never text, never an icon, never the sole indicator of state. Ink on maize is 11.1:1 (AAA). On the dark ground it is unrestricted at 11.36:1.

Motion

Every animation must hold 60fps on an entry-level handset: a 16.7ms frame budget, and in practice only transform and opacity.

Duration

TokenValueCSSNotes

slow 380ms --motion-duration-slow Entrances, expansions, meters.
