# @mymzansi/web

The **web component library** for the MyMzansi design system — React +
Tailwind v4 + shadcn/Radix, built entirely on the tokens generated by the
repo root.

This package is deliberately self-contained: it has its own `package.json`
and dependency tree, and **does not touch the repo root**, whose
zero-dependency token core (`tokens.json` → `dist/`) stays exactly as it
was. See `BRAND.md` §14 for why that separation matters for a public-sector
repo.

## How it consumes the tokens

`src/index.css` imports the **generated** outputs from the repo root — never
a hand-copied value:

- `../../../dist/css/tokens.css` — the CSS custom properties (light default,
  dark via `prefers-color-scheme`, plus an explicit `[data-theme]` override).
- `../../../dist/tailwind/tailwind.config.js` — the Tailwind bridge, so
  utilities like `bg-theme-accent`, `text-title3`, `p-md`, `rounded-lg`,
  `duration-quick` map straight onto tokens.

If `tokens.json` changes, re-run `npm run build` at the repo root and this
package picks the change up with no edits here.

The shadcn/Radix vocabulary (`--primary`, `--muted`, `--destructive`…) is
aliased to real MyMzansi tokens in `src/index.css` — so `npx shadcn add`
drops in a component that is already on-brand, in both themes, with no
`dark:` variants to maintain.

## Components (Phase 1)

Button · Card · Input · Badge · StatusRow · Section · Sheet · Switch ·
Checkbox · RadioGroup · Divider · Avatar · Skeleton · EmptyState

Each has a `*.stories.tsx` documenting its variants, states and both
themes. Rules each component encodes (no hardcoded values, no colour-only
state, 44px targets, no uppercase headings, transform/opacity-only motion,
reduced-motion honored) are cited inline against `BRAND.md`.

## Scripts

```bash
npm run dev         # Vite dev server (the App.tsx kitchen-sink page)
npm run storybook   # Storybook — the canonical component documentation
npm run build       # tsc + vite production build
```

## Fonts & icons — R6 (no external origins)

- **Montserrat** is self-hosted via `@fontsource-variable/montserrat`. It
  passed BRAND.md §5.4's own coverage test (click consonants ǀǁǂǃ + full
  diacritics) where the trendier candidates failed — see the repo history.
- **Material Symbols Outlined** is self-hosted via `material-symbols` — the
  icon family BRAND.md §6 has always specified. This is the first platform
  where the actual documented icon decision applies (the RN app could only
  approximate it with @expo/vector-icons).

Nothing loads from a CDN.
